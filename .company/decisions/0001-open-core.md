# 0001 — Open Core First

## Decision
Keep the V0 CLI, local reporting, and core policy workflow open in the repository.

## Context
The project needs developer adoption and trust before a hosted control plane is justified.

## Alternatives
- Hosted-only SaaS: rejected for V0 because it raises activation friction.
- Closed CLI: rejected because it weakens reproducibility and distribution.

## Evidence
Design decision only; no market-performance claim is asserted.

## Revisit when
Repeated usage shows teams want shared history, private datasets, RBAC, SSO, or hosted runners.
