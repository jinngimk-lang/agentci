# Strategy

## Wedge

Start with deterministic agent evals and GitHub-native reliability checks. Earn adoption by making regressions visible before merge.

## Expansion rule

Only expand toward agent security, observability, MCP governance, or hosted team workflows after usage evidence shows the eval workflow is repeatedly valuable.

## Distribution

Prefer evidence-producing engineering: reproducible benchmarks, datasets, failure modes, measurable improvements, and working integrations. Marketing is downstream of verified artifacts, never a calendar quota.
